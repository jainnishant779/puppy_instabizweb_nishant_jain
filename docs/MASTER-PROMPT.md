# Master prompt

> Build a responsive, independently implemented recreation of https://puppy.instabizweb.com/ from its publicly rendered pages. Inspect desktop and mobile before building. Document the page hierarchy, visual tokens, controls, destinations, route parameters, and empty states. Use the media provenance list and the observations in the reference audit to ground the implementation.
>
> Build with semantic HTML, CSS, and browser JavaScript. Generate each route as a real static page so a copied URL or hard refresh works on a GitHub Pages project path. Use shared templates for header, footer, buttons, cards, gallery, and forms. Keep puppy, family, and FAQ data outside the templates. Include Home, Available puppies, Happy families, How it works, FAQ, Visit & contact, Gone home, and each puppy profile.
>
> Match the reference’s warm, illustrated storybook style. Use Fraunces for oversized rounded headings, Figtree for body and navigation, and Shantell Sans for handwritten notes. Use milk, honey, cinnamon, espresso, and a green WhatsApp accent. Recreate the cream hero, puppy lineup, Teddy mascot, stitched quilt, rows of arched doors, travel signposts, illustrated chat, passport stamps, polaroid gallery, dark FAQ, and welcome-home scene. Recreate sketchbook listing portraits, gallery wallpaper, FAQ pinboard, contact letter, and gone-home tickets. Keep strong outlines, soft paper shadows, irregular edges, and the gradual transition to night.
>
> Match desktop and mobile behavior. Use the full navigation with active-link markers on desktop and an accessible menu plus fixed WhatsApp and Call bar on mobile. Provide keyboard focus, reduced-motion handling, and responsive layouts with no horizontal overflow. Use the captured public puppy media and font files locally, resize images for the web, and lazy-load offscreen media.
>
> Implement catalog filters for origin, breed, and sex with shareable URL state, count, reset, and empty results. Make profile galleries support photos, videos, previous and next, thumbnails, fullscreen, and keyboard navigation. Include all 64 family photos and the archived puppy route. Make the process tabs and section links usable. Add FAQ search over questions and answers, expandable notes, and an empty state. Build enquiry forms with required name and phone validation plus optional email, area, puppy, and message. Open a clearly labeled WhatsApp draft on submit and keep the visitor in control of sending. Document the change from the reference’s server-side form.
>
> Verify desktop and mobile pages and controls in a browser. Check local assets, media playback, deep links, direct page loads, filters, gallery navigation, FAQ search, mobile navigation, and validation. Publish the site and full source, and capture a screen walkthrough covering the inspection and implementation process, layout, code, tools, exact AI prompts, decisions, tests, and deployment. Report any divergence and provide the live, GitHub, and Loom URLs when verified.
